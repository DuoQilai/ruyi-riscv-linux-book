用 CIPP 四层看这门课

标准问四件事，这门课每一件都落在板上。成效按 OBE 写：目标可观察，用证据判断。

#四层标准 × 这门课的落点
层标准问什么这门课落在哪
1为什么开、对谁有价值Context 初学者用 C 在荔枝派 4A 上，从交叉编译一路做到真板上温控闭环（ch01–04）
2条件与资源齐不齐Input 荔枝派、继电器、风扇、DHT22、TXS；讲义、实验、脚手架、make sol 逐章齐备
3讲义实验按主线落地Process 每章讲义三节 + 一份实验；一章补一块能力，工具链 → C → GPIO → 真传感器 → 命令
4学生在板上能演示什么Product CoreMark 跑分过校验；风扇按阈值转；status / set temp 立刻生效；Ctrl+C 先关风扇
##成效看板上现象，不看口号
  • -风扇跟着模拟温度开停，改阈值后开/关点跟着变
  • -敲 status 立刻出温湿度，set temp 改阈值立刻生效
  • -打字时自动控温不停（select 一边等采样，一边等你敲命令）
  • -前序能力串成闭环：模拟温度 → 真采样 + 运行中改阈值
