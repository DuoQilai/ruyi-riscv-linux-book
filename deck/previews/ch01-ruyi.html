第一章讲义 · §1.1 荔枝派 4A 与 RuyiSDK

安装 RuyiSDK

RuyiSDK 是面向 RISC-V 开发的工具包集合；命令入口叫 ruyi。ruyi 管「装什么」，GCC 管「怎么编」。

本课三元组钉死为 riscv64-ruyisdk-linux-gnu：为 64 位 RISC-V、跑 Linux 的用户态交叉编译。

  1. 1
    在 x86 Linux 上 uname -m，确认是 x86_64。
  2. 2
    ruyi update，再 ruyi install gnu-ruyisdk。
  3. 3
    ruyi venv -t gnu-ruyisdk manual venv-gnu-ruyisdk
  4. 4
    . ~/venv-gnu-ruyisdk/bin/ruyi-activate — 每次新开终端都要重新激活。
  5. 5
    riscv64-ruyisdk-linux-gnu-gcc -dumpmachine 应打印同一三元组。
# 以下均在 x86 Linux 上执行
$ . ~/venv-gnu-ruyisdk/bin/ruyi-activate
$ riscv64-ruyisdk-linux-gnu-gcc -dumpmachine
riscv64-ruyisdk-linux-gnu
