# Docs

存放课程大纲、制作计划、制作规范和模板。

## 课程基准

- [`CourseOutline.html`](CourseOutline.html)：完整课程设计（术语表、章节表、BOM、硬规则）。
- [`index.html`](index.html)：跳转至 `CourseOutline.html`。
- `course-outline.md`：ch01/ch02 章节摘要（指向 HTML 大纲）。
- `course-plan.md`：制作进度（Markdown，无 Excel）。
- `course-production-spec-v1.md`：制作规范（节讲义、HTML 幻灯片、实验）。

## 模板

- `templates/course-document-template.md`：节讲义模板。
- `templates/lab-template.md`：实验指导书模板。
- `templates/ppt-template.md`：历史 PPT 模板（新内容用 HTML，见 `slides/README.md`）。
- `templates/asset-guidelines.md`：图片与图表规则。

## 后续可补

- `faq.md`：常见问题。
- `errata.md`：勘误。
