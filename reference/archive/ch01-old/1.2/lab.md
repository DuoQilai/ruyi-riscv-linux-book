## 实验目标

- 校验课程指定 RevyOS 镜像并安全完成烧录。
- 通过串口或显示器观察首次启动并进入 shell。
- 完成系统、用户、网络、时间和 apt 软件源检查。
- 建立不依赖网络的串口备用调试通道。
- 建立可核验目标身份的 SSH 登录通道。
- 完成 SCP 双向传输与文件完整性校验。

## 实验任务

### 任务 1：校验镜像并完成烧录

记录镜像来源、文件名、发布日期、板卡型号、校验值和目标介质，按发布说明完成烧录并观察首次启动。

### 任务 2：完成首次启动检查

确认系统、架构、用户、网络、时间和软件源。

### 任务 3：建立串口备用通道

完成串口接线，观察启动日志并进入 shell。

### 任务 4：配置 SSH 密钥登录与 SCP 传输

确认 SSH 服务和板端身份后配置公钥，完成双向文件传输并校验哈希。

## 实验步骤

### 第一部分：镜像烧录与首次启动

1. 计算并比对镜像哈希。

```bash
sha256sum <image-file>
```

2. 让开发板进入镜像说明要求的烧录模式。
3. 使用烧录工具列出设备，确认目标唯一。
4. 按发布说明执行烧录并保存日志。
5. 启动后通过串口或 HDMI 观察启动过程，等待进入 shell。
6. 执行系统检查：

```bash
cat /etc/os-release
uname -a
uname -m
id
hostnamectl
```

7. 检查网络、时间与软件源：

```bash
ip -br addr
ip route
timedatectl
grep -R --no-filename -h '^deb ' /etc/apt/sources.list /etc/apt/sources.list.d 2>/dev/null
sudo apt update
```

### 第二部分：开发通道建立

8. 断电完成串口接线（GND-GND、TX-RX 交叉），打开终端后启动开发板，确认串口可用。
9. 在板端启用 SSH 并记录地址：

```bash
ip -br addr
sudo systemctl enable --now ssh
sudo systemctl status ssh --no-pager
```

10. 主机首次 SSH 登录，核对指纹：

```bash
ssh <user>@<board-ip>
```

11. 配置密钥登录：

```bash
ssh-keygen -t ed25519 -C "riscv-course"
ssh-copy-id <user>@<board-ip>
ssh <user>@<board-ip> 'hostname; uname -m'
```

12. 上传测试文件并校验：

```bash
printf 'RISC-V course transfer test\n' > transfer-test.txt
sha256sum transfer-test.txt
scp transfer-test.txt <user>@<board-ip>:/tmp/
ssh <user>@<board-ip> 'sha256sum /tmp/transfer-test.txt'
```

13. 下载板端文件：

```bash
scp <user>@<board-ip>:/etc/os-release ./board-os-release.txt
sed -n '1,10p' board-os-release.txt
```

## 验收记录

| 记录项 | 内容 |
| --- | --- |
| 运行命令 | 校验、烧录、系统检查、串口参数、SSH、SCP 与哈希命令 |
| 关键输出 | 哈希、系统版本、内核、IP、apt 结果、服务状态、主机名、架构 |
| 截图或照片 | 烧录成功、首次登录、串口登录、SSH 登录、传输成功 |
| 异常处理 | 无设备、无启动、无网络、超时、拒绝连接、指纹变化或权限问题 |

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 校验值不一致 | 下载不完整或文件版本错误 | 删除损坏文件并重新下载 |
| 烧录中断 | 线缆、权限、供电或主机休眠 | 更换可靠连接并重新开始 |
| 无启动画面 | 显示通道问题或镜像未启动 | 使用串口判断实际启动状态 |
| apt 失败 | 网络、DNS、时间或仓库问题 | 按错误类型分别排查 |
| 串口乱码 | 波特率错误或线路不稳 | 按板卡资料重新设置并检查接线 |
| SSH 超时 | IP、网段、路由或防火墙问题 | 从串口检查地址、路由和服务 |
| 指纹冲突 | 重装系统或 IP 被复用 | 先核对目标身份，再更新记录 |
| SCP 权限失败 | 目标目录不可写 | 传到用户目录或 `/tmp` |
