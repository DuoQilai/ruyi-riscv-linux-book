讲义与本章实验

文档 解决什么问题 学生要交出什么
讲义（lecture） 零件是什么、接口怎么用；概念在首次出现处讲透；带跟做小例子 跟做后单项能力会了，例如 gpioset 控继电器、能解释 select
本章实验（lab） 用本章零件做完整验收；给 C 脚手架 + 契约 + 验收标准 能演示约定现象（如风扇开/关、敲 status 有回复），并填记录表
  • 讲义 → 同章实验 → 下一章讲义；底栏有「上一篇 / 下一篇」。
  • 实验写差量步骤与验收；安装 / make / scp 等基础操作以讲义为准。
  • 同一故事线递进：ch02 软件模拟温度 → ch03 模拟温度+真风扇 → ch04 真传感+命令对话。

术语表

读章节总览前可先扫一眼；各章细则表内仍有章节专属名词。每个词用一句话说清「它是什么」。

术语 说明
荔枝派 4A 本课用的 RISC-V 开发板；板上已跑 Linux，用 SSH 或串口连上去写程序。
RuyiSDK / ruyi 如意课题组的 RISC-V 开发工具入口：装交叉编译器、系统镜像、查板卡支持列表。
交叉编译 在电脑上编出只能在开发板上跑的程序，再拷到板子上运行。
SSH / SCP / 串口 SSH：远程登录板子敲命令。SCP：把文件拷到板子。串口：USB 线连上后的「聊天线」黑窗口，打字板子能看见。
CoreMark 测板子算力的小程序。ch01 实验：交叉编译后上板跑出分数并记录。
GPIO 板子上一排针脚。本课主要写输出（继电器信号端）；也可读输入（传感器数据线）。
gpiod Linux 上读写 GPIO 的常用接口库；ch03 用它控风扇继电器。
MMIO 把硬件寄存器当成内存地址来读写。Linux 里内核管着这些地址；用户程序经 gpiod 间接访问。ch03 用只读方式核对某一位翻转。
devmem 按地址读/写内存的小工具。ch03 只读：改 GPIO 电平前后各读一次，看到对应位翻转。
DHT22 温湿度探头。数据线经电平转换接 GPIO；ch04 起用，综合项目由 Agent 工具读取。
TXS / AMS1117 TXS0108E：1.8 V↔3.3 V 双向电平转换。AMS1117-1.8V：给 TXS 低压侧（VA）供电。ch04 接 DHT22 时用。
继电器 用小信号开关大电流的模块。板子 GPIO 驱动继电器，继电器再给风扇通断电。ch03 起用。
阈值 / 滞回 高于上限开、低于下限关，中间保持。ch02 在软件里练；ch03 接到真风扇；ch04 可用 set 现场改温度上下限。
终端命令 在 SSH 窗口打字，程序认命令。例：status 查状态，set temp 30 改温度 bar。工程目录 chapters/ch04/code/。
select 让程序同时盯几个输入源。ch04：一边等采样周期到，一边等你在 SSH 里打字。
MQTT 物联网发消息的方式。电脑终端和板子都连一个「中转站」，按主题名收发文字（如主题 home/led 发 on）。
Broker MQTT 的中转站。常用软件叫 Mosquitto，可跑在电脑或板子上。
发布 / 订阅 发布＝往某主题发一条消息；订阅＝盯着某主题收消息。ch05：电脑终端下行控外接 LED；板子上行发布状态。
tcpdump 抓网络包的工具。ch05：抓一条 MQTT 发布，亲眼看到消息被一层层包起来发出去。
外接 LED 远程控制用的灯。ch05：电脑终端发 MQTT 命令，板子驱动这盏灯。
DeepSeek Harness Agent 运行时（dsh）。会话、工具、模型、界面都是插件。本课在终端里打字对话，像 Claude Code；不把网页当主入口。
pthread / 多线程 一个程序里同时跑多段逻辑。ch06 三线程：采集 ∥ 控制 ∥ 通信(MQTT)。
竞态 两条线同时改同一份数据，结果写乱。ch06：先故意不加锁看数据错乱，再加锁修好。
ThreadSanitizer 编译时加上 -fsanitize=thread 的检查器。ch06：在电脑上编同一个抢数据小程序，终端打印哪两行在抢同一变量。
llama.cpp / GGUF C++ 本地推理栈。量化得到 .gguf；K3 上用带 IME2 的 llama-server 提供 OpenAI 兼容 HTTP。
量化 把较高精度权重量成更少比特（本课至少 Q4）。学生自己压，记下体积，并确认工具调用仍在。
模型供应商 Harness 里的脑子来源。本地填 K3 的 llama-server 地址，云端填 DeepSeek API。同一套工具，只换 baseURL。
端侧 Agent 环境终端 本课综合大项目：荔枝派三线程滞回一直转；人在终端 Harness 里打字；工具经 MQTT 动手；本地量化模型与云端 DeepSeek 可替换。
