# 如意 RISC-V Linux 实践课 · 课程评价标准

## 这套评价方式好在哪里

先说方法。本课用 **CIPP 四层** 来评价一门实践课，顺序就是课程从立项到验收的顺序：

| 层 | CIPP | 本课对应 | 这一层看什么 |
|----|------|----------|--------------|
| 1 | 背景 Context | 开课意义 | 为什么开、对谁有价值 |
| 2 | 输入 Input | 条件与资源 | 板、工具链、讲义与实验的齐备程度 |
| 3 | 过程 Process | 教学实施 | 讲义与实验按主线落地的程度 |
| 4 | 成果 Product | 学习成效 | 学生在板上能演示什么 |

四层分开写，评价有统一口径：意义、条件、教法、成效各归一层。

**成效这一层按 OBE 写：** 目标是可观察的行为，达成用证据来判断。工程实践课再吸收 **CDIO**：项目驱动、验收式演示。看的是风扇转、命令有回复、跑分过校验这类板上结果。

文末给出 CIPP、OBE、CDIO 的来源。下面用这套口径说明已经落地的第 1–4 章。

## 1. 开课意义

对应 CIPP **背景（Context）**：为什么开这门课、对谁有价值。

| 编号 | 好在哪里 | 第 1–4 章里的落点 |
|------|----------|-------------------|
| 1.1 | 谁学、学完能在板上做什么，写得具体 | 初学者用 C 在荔枝派 4A 上走通通道（ch01）、写出够用的控温逻辑（ch02），再让风扇和传感器按规则动起来（ch03 / ch04） |
| 1.2 | 实践与真板路径清楚 | 验收看板上现象：CoreMark 跑分、继电器吸合、风扇开闭、`status` / `set` 立刻改阈值 |
| 1.3 | 与 RuyiSDK / 如意生态的关系清楚 | ch01 用 `venv-gnu-ruyisdk` 交叉编译，三元组钉死为 `riscv64-ruyisdk-linux-gnu`；板上也可用本机 `gcc` 复跑同一份源码 |

## 2. 条件与资源

对应 CIPP **输入（Input）**：开得出、跑得起来的条件。

| 编号 | 好在哪里 | 第 1–4 章里的落点 |
|------|----------|-------------------|
| 2.1 | 硬件与物料可执行 | ch03 荔枝派 4A + 继电器 + 风扇；ch04 加上 DHT22 与电平转换。排针、接线表和实物照片在实验页 |
| 2.2 | 工具链与开发通道可复现 | ch01：交叉编译、`file` 认 RISC-V、SCP 哈希对照、SSH 上板；每章 Makefile 按机器自动选编译器 |
| 2.3 | 讲义、实验、脚手架可获取 | 每章 `lecture.html` + `lab.html`；学生代码留 TODO，教师用 `make sol` 验收参考实现 |

## 3. 教学实施

对应 CIPP **过程（Process）**：设计好的教法按主线落地。

| 编号 | 好在哪里 | 第 1–4 章里的落点 |
|------|----------|-------------------|
| 3.1 | 章节结构统一，讲义与实验分工清楚 | 每章讲义三节 + 一份完整实验。讲义跟做学概念；实验换目标、换证据来验收 |
| 3.2 | 实验步骤可跟做，验收现象写清楚 | 每章实验有步骤、排错和验收表。例如 ch01 要 `file` / 哈希 / 跑分；ch03 要阈值开闭风扇；ch04 要 `status` / `set` 立刻有回复 |
| 3.3 | 主线连贯，一章补一块能力 | 环境与工具链（ch01）→ 够用的 C 与命令表（ch02）→ GPIO 驱动风扇（ch03）→ 真传感器 + 命令改阈值（ch04） |

---

## 4. 学习成效

对应 CIPP **成效（Product）**：目标可观察，用证据判断达成。

| 编号 | 好在哪里 | 第 1–4 章里的落点 |
|------|----------|-------------------|
| 4.1 | 目标写成板上能演示的行为 | 编出 RISC-V 可执行文件、滞回按契约动作、风扇按阈值转、敲一行命令改控温 |
| 4.2 | 章实验有明确证据 | CoreMark 分数与 `Correct operation validated`（ch01）；假温控六步 OFF/ON/READ_FAIL（ch02）；29°C 开 / 25°C 关（ch03）；`status` 读温湿度、`set temp 20` 后选择开风扇（ch04） |
| 4.3 | 前序能力已经能串成可演示闭环 | ch03 的继电器风扇接到 ch04 的 DHT22 与命令表：同一套执行器，从假温度走到真采样 + 运行中改阈值 |
