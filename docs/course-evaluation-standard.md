# 如意 RISC-V Linux 实践课 · 课程评价标准

课题组自评用。全文四部分、共 12 条；每条 0–10 分；**不算**「合格 / 优秀」标签，只保留分数。

本标准是课题组自定的**统一口径**。结构取 CIPP 四层（开课意义 / 条件与资源 / 教学实施 / 学习成效）；成效条目写法取 OBE「可观察目标 + 证据」；工程能力评价吸收 CDIO「项目驱动、验收式演示」思路。来源见文末——**不照搬**条文，只取思路。

---

## 计分规则

1. 四部分等权，各占 **25%**。
2. 每部分 **3 条**，部分内等权：该部分得分 = 三条分数加起来再除以 3。
3. 课程总分 = 四个部分得分加起来再除以 4（满分 10）。
4. 评分人：课题组自评。

**说白了（数字演示）**

假设「开课意义」三条自评是 8、7、9：

- 该部分得分 = (8 + 7 + 9) ÷ 3 = **8**
- 若四部分得分分别是 8、7.5、8.5、9，则课程总分 = (8 + 7.5 + 8.5 + 9) ÷ 4 = **8.25**
