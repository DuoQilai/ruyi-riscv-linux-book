# Ruyi RISC-V Linux 嵌入式实践课 · 课程说明

本文档说明本课程的整体定位、设计理念，以及与官方《RuyiSDK RISC-V 嵌入式编程技术》课件框架（下称「课件框架」）的章级对照关系。课程详细规划以 [`CourseOutline.html`](./CourseOutline.html) 为准。

---

## 一、课程是什么

本课程是一门面向本科或初学者的 **RISC-V Linux 嵌入式实践课**。学生在 **真实 RISC-V 开发板**（如 LicheePi 4A，以 [RuyiSDK support-matrix](https://github.com/ruyisdk/support-matrix) 为准）上，用 **C 语言** 完成从环境搭建、交叉编译、外设控制到联网通信与综合项目交付的完整流程。统一工具入口为 **RuyiSDK（`ruyi`）**。

课程不是「纯理论 + 零散 Demo」，而是围绕 **三个递进项目** 组织：

| 阶段 | 项目 | 能力闭环 |
|------|------|----------|
| 实验 1 | 温控风扇 | 读温湿度 → 阈值判断 → 控风扇 |
| 实验 2 | MQTT 远程控灯 | 手机 → Broker → 开发板 → LED |
| 综合项目 | 智能环境终端 | 整合前述能力 + 配置/日志/多线程 + 边缘时序异常检测 |

板载应用一律用 C 实现；机器学习部分采用 **PC 端轻量训练 → 导出 `weights.h` → 开发板 C 推理**，不讲完整深度学习理论，重点在部署闭环。

## 二、设计理念

**1. 项目驱动，而非知识点堆砌**

先让学生能「做出一个能跑的东西」，再回头补原理。章节按技能链排列：环境 → 工具链 → 外设 → 可维护应用（文件/配置/日志）→ 网络 → 多线程 → 综合组装。

**2. 一门课一条主线**

主线固定为：**RuyiSDK + 交叉编译 + C 应用 + 真机验证**。OpenCV、YOLO、Buildroot、RVV 专题等不进主线，可作为选修扩展。

**3. 讲义能自学，实验能验收**

- **讲义**（`chapters/chXX/lecture.html`）：概念、图示、可跟做步骤。
- **实验**（`chapters/chXX/lab.html`）：在讲义跑通后的整合验收或独立动手，不重复讲义里的命令块。
- 改结构、改实验归属时，**先改 `CourseOutline.html`**，再改章节内容。

**4. 可观察、可答辩的成果**

每章有明确「章节成果」；综合项目要求可演示、可说明模块分工、有日志与配置，能作为课程结业作品。

## 三、与课件框架的章级对照

官方课件框架将课程分为六章（每章四个教学单元，配套讲义、PPT、实验指导书）。本课程仍覆盖同一学科领域，但按项目需要 **重新划分章节与侧重点**。下表为 **章级** 对照，便于审核或协作时对齐范围。

| 课件框架章节 | 本课程对应 | 覆盖情况 | 说明 |
|--------------|------------|----------|------|
| 第一章：RISC-V C 语言开发与调试 | ch01 开发环境 + ch02 工具链与首个 C 程序 | 已覆盖，顺序前置 | 调试能力（SSH/串口、交叉编译排错）融入环境与工具链两章，而非单独「C 语法课」；全课以 C 应用为主线贯穿。 |
| 第二章：GPIO、UART、常用外设 | ch03 GPIO / UART / 外设 | 已覆盖，并扩展 | 除 LED、串口、温湿度、PWM 外，含状态机与 **实验 1（温控风扇）** 作为章内综合验收。 |
| 第三章：程序库、进程与线程 | ch06 线程与任务协同；ch04–ch05 中的库使用 | 部分拆分 |  pthread / 多线程独立成章；进程、IPC 等未作专章，以「能支撑综合项目多任务架构」为尺度取舍。 |
| 第四章：文件系统与网络编程 | ch04 文件 / 配置 / 日志 + ch05 网络与 MQTT | 已覆盖，拆为两章 | 文件 I/O 与可维护应用结构先于网络；物联网场景以 **MQTT** 为主，而非通用 socket 大全。 |
| 第五章：RISC-V 向量扩展（RVV）加速编程 | 不在主线 | 未纳入 | 入门实践课优先「端到端项目闭环」；RVV 可作为后续进阶或选修材料。 |
| 第六章：机器学习 | 综合项目（智能环境终端） | 以部署视角覆盖 | 不做整章 ML 理论；PC 训练 tiny 模型 + 板端 C 推理 + 与规则控制共存，满足「边缘智能」实践目标。 |
| （框架未单列） | 综合大项目 | 本课程增设 | 整合 ch01–ch06 与实验 1/2，形成可答辩的完整作品。 |

**小结：** 六章主题大部分仍能对应到本课 ch01–ch06 与综合项目；主要差异是 **章节顺序按项目技能链重排**、**RVV 未进主线**、**机器学习收敛为综合项目中的边缘推理**。这些调整是为了在有限学时内保证学生能完成可演示的完整系统，而非削减 RISC-V 嵌入式核心能力。

## 四、从课件框架借鉴的制作标准

课件框架附带的文档 / PPT / 实验审核表条目较多。本课程 **选取其中仍适用于我们交付形态的原则**，归纳为以下几条，不逐条照搬表格。

| 借鉴原则 | 在本课程中的体现 |
|----------|------------------|
| 内容清晰、术语规范、可独立阅读 | 讲义面向初学者，名词首次出现有解释；技术名词大小写与业界一致（如 RISC-V、MQTT、GPIO）。 |
| 知识点讲透、体量均衡 | 以 `CourseOutline.html` 每章目标为准，避免某章过薄或堆砌无关扩展。 |
| 图表与代码配有说明 | 重点操作配流程图或截图；代码块后有用途说明与 **运行验证** 步骤。 |
| 实验可完成、可验证 | 实验须在目标开发板上跑通；参考课件框架「练习不宜过长」的精神，单实验控制在合理课堂/实验课时段内。 |
| 少用第三方整段搬运 | 引用资料注明出处；练习截图与命令以本机/本板验证为准。 |
| 交付物结构统一 | 章节目录与 outline 对齐；讲义 + 实验分工明确（见 README 工作流）。 |

**与框架原文的差异（客观说明，非否定）：**

- **交付形态：** 框架要求每单元「讲义 + PPT + 实验指导书」三套 Markdown；本仓库采用 **HTML 讲义 / 实验**（可导出 PDF），幻灯片内容与讲义同源，减少重复维护。
- **实验平台：** 框架实验审核表提及 XBot-U Gazebo / 机器人；本课面向 **RISC-V Linux 开发板 + RuyiSDK**，与课程名称及硬件 BOM 一致。
- **进度跟踪：** 日常以 Git 与 `CourseOutline.html` 为准；框架 Excel 进度表可作对外汇报参考，不作仓库内唯一真相源。

## 五、本课程采用的简要评价标准

用于自检章节与综合项目是否「够格」，不替代学院正式审核流程。

1. **可运行：** 讲义中的关键步骤能在目标板或约定环境中复现。
2. **可验收：** 每章 lab 有明确通过标准（如连通、跑分、控灯、告警等）。
3. **可衔接：** 综合项目能复用实验 1/2 模块，而非重写一遍。
4. **可维护：** ch04 起强调配置、日志、目录结构，综合项目须能现场排错。
5. **可演示：** 综合项目能在「正常 / 异常」场景下展示风扇、LED、MQTT 联动。
6. **符合课规：** C 语言板载应用、RuyiSDK 工具链、交叉编译 + Makefile（或等价模板）、PC 训练 / 板端推理分工（见 outline「硬课规」）。
