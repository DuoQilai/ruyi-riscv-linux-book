# 课程代码目录

本目录用于统一存放课程项目代码、实验代码和课后题代码。当前阶段只保留本说明文件，后续根据实际项目逐步新增代码目录。

## 目录约定

后续按项目建立独立目录，每个项目目录包含自己的说明、源码、配置和运行验证材料。

```text
code/
└── project-name/
    ├── README.md
    ├── src/
    ├── include/
    ├── config/
    └── data/
```

## 命名规则

- 项目目录使用小写英文、数字和连字符，例如 `ruyi-toolchain-check/`。
- 能独立构建的代码项目，应包含自己的 `README.md` 和统一构建入口。
- 项目 `README.md` 应说明项目目标、对应课程内容、构建方法、运行方法和验收现象。
- 如果某一讲没有真实代码材料，不需要为它制造空目录；讲义和实验指导书直接说明该讲以环境记录或操作验证为交付物。

## 与文档的关系

- 讲义只展示必要片段和关键命令，完整工程放在对应项目目录中。
- 实验指导书引用代码时，应写明 `code/<project-name>/` 路径、执行方式和验收现象。
- 课后题或拓展练习如需要代码，也按项目放入本目录。
