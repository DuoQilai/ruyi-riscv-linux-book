# 第6章第3讲：TinyML KWS 语音关键词识别控灯

## 项目定位

本项目对应新版 6 章大纲中的 `ch06.3 TinyML 边缘推理实战`，是第 6 章边缘智能方向的第三讲实验。

项目目标是在 LicheePi 4A + RevyOS 上完成“音频输入 -> MFCC 特征 -> int8 KWS 推理 -> 关键词 -> GPIO/PWM 灯光动作”的完整闭环。Face Detection、YOLO、LLM/VLM 控制设备只作为第 6 章其他讲次或课程设计拓展，不作为本讲默认验收路径。

## 复用章节

| 来源章节 | 复用能力 | 在本项目中的用途 |
| --- | --- | --- |
| ch01 | RevyOS、RuyiSDK、SSH/SCP、串口、自动化部署 | 部署程序、上传样本、查看日志 |
| ch02 | GPIO/PWM、LED、按键、UART、常用外设 | 执行“开/关/闪”和本地调试 |
| ch03 | 库封装、进程、线程、生产者-消费者 | 支撑音频采集与推理任务协同 |
| ch04 | 文件、配置、日志、网络状态回传 | 管理样本、配置阈值、记录推理结果 |
| ch06.1 | 摄像头与 OpenCV 的边缘采集思路 | 对比视觉采集和音频采集流程 |
| ch06.2 | 轻量推理框架和量化部署 | 衔接 int8 模型部署和性能记录 |

## 默认实现

| 项目 | 默认要求 |
| --- | --- |
| 开发板 | LicheePi 4A |
| 操作系统 | RevyOS |
| 关键词 | “开”“关”“闪” |
| 输入 | 麦克风实时输入；若硬件不稳定，允许预录音频文件注入 |
| 特征 | MFCC |
| 推理 | int8 KWS 轻量模型 |
| 输出 | LED 点亮、熄灭、闪烁，或 GPIO/PWM 灯光模块动作 |
| 日志 | 关键词、置信度、推理耗时、失败回退 |

## 实验拆分

| 实验 | 任务 | 验收 |
| --- | --- | --- |
| Lab 1 | 准备“开/关/闪”样本，提取 MFCC，导出 int8 参数或 `weights.h` | 能生成样本清单、特征结果和模型参数 |
| Lab 2 | 在 LicheePi 4A + RevyOS 上部署 KWS 推理程序 | 能输出关键词、置信度和推理耗时 |
| Lab 3 | 集成 GPIO/PWM 灯光动作 | 喊“开”灯亮，喊“关”灯灭，喊“闪”LED 闪烁 |

## 备用方案

| 风险 | 备用处理 |
| --- | --- |
| 麦克风不可用 | 使用预录音频文件作为输入 |
| 实时音频链路不稳定 | 先用文件注入完成推理和控灯闭环 |
| KWS 模型准备超出课时 | 使用预导出的 `weights.h`，课堂重点放在板上推理和动作映射 |
| GPIO/PWM 灯光不可用 | 用终端输出关键词动作，保留板端推理和日志验收 |
| 语音方案整体受阻 | 使用温湿度异常检测 fallback，但仍保留 TinyML 训练、量化、部署和告警闭环 |

## 验收标准

- 能在 LicheePi 4A + RevyOS 或等效实验环境中运行 KWS 推理程序。
- 能输出关键词、置信度和推理耗时。
- 喊“开”时 LED 或灯光模块点亮。
- 喊“关”时 LED 或灯光模块熄灭。
- 喊“闪”时 LED 闪烁。
- 能说明预录音频 fallback 与实时麦克风方案的边界。
- 能把本项目定位到第 6 章第 3 讲，不再引用旧版章节编号。
