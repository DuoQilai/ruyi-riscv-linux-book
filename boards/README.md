# Boards

存放开发板相关配置、设备说明、镜像烧录说明和外设连接说明。

## 板卡口径

- `licheepi4a/`：LicheePi 4A，本课程新版 6 章大纲的主线开发板。
- `k1/`：K1 / Muse Pi Pro，保留为扩展板卡、资料参考和后续适配方向。

课程正文、实验指导和 slides 默认围绕 LicheePi 4A + RevyOS 展开。涉及镜像、串口、登录账号、GPIO 编号、设备路径和外设接线的板卡差异，统一放在本目录下维护。

K1 / Muse Pi Pro 相关资料可以继续保留，但不得覆盖 LicheePi 4A + RevyOS 主线，也不得把新版课程改回多板主线。
