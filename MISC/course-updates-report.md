## 总体说明

这一轮工作按照评审意见逐条落实：以实验产出作为章节题目，为每个知识点配备最小化的实例，并注意知识的递进性，从浅到深、节节提高。具体来说，我们为各章知识点补充了真实测试过的引导实例，新增了完整可运行的示例程序（包括源码和 Makefile，并已在板子上验证通过），同时对课件结构做了调整，让主线更加清晰。

## 第 1 章

### 与 ruyiSDK 相关的内容

第 1 章是 ruyiSDK 内容最集中的一章。我们补充了 ruyiSDK 的完整安装流程，包括通过 PyPI 安装、检查 PATH 并验证版本、执行 `ruyi update` 和 `ruyi install gnu-ruyisdk` 安装工具链、使用 `ruyi venv` 创建虚拟环境并激活，最后验证交叉编译器能够正常输出 `riscv64-ruyisdk-linux-gnu` 三元组。

在此基础上，我们加入了 `ruyi device provision` 一键烧录的主路径：该命令可以交互式地下载并写入 RevyOS 镜像，底层走 fastboot，对应的包索引是 `revyos-sipeed-lpi4a` 与 `uboot-revyos-sipeed-lpi4a-16g`，并附上了 ruyiSDK Support Matrix 中 LicheePi 4A / RevyOS 的链接作为参考。

此外，我们还增加了一个最小程序的交叉编译演示：交叉编译一个 mini 程序，用 `file` 识别其架构，并在实机上演示跨架构程序被内核拒绝、报 `Exec format error` 的过程，让学员直观理解「指令集不同，程序不能互换」。

### 其他新增内容

- 讲解部分补充了三元组逐字段拆解（CPU-厂商-系统）、对同一份源码用两种编译器编译后反汇编对比、ELF 文件中 `e_machine` 字段的作用，以及串口、SSH、SCP 三条通道的对比。

## 第 2 章

本章为各个知识点补充了浅色的引导实例，包括整数除法截断与类型转换（如计算温度占比）、`static` 关键字的文件内可见性、传值与传指针的区别（对应实验中 `read_temp(&t)` 的用法），以及数组名即首元素地址、函数内 `sizeof` 拿不到数组长度等常见陷阱。

## 第 3 章

### 与 ruyiSDK 相关的内容

第 3 章明确了统一的交叉编译工作流：学员在 x86 Linux 主机上激活 `venv-gnu-ruyisdk` 后交叉编译，再把产物拷贝到荔枝派上运行；同一份 Makefile 在板子上会自动改用板载 gcc，若主机交叉编译因缺少 libgpiod 失败，也可以直接在板子上执行 `make`。

### 其他新增内容

- 建立了「外设等于寄存器、控制等于改位」的心智模型，把第二章的位运算落到硬件上，说明 gpioset、gpiod 等工具做的其实是同一件事。
- 给出了本板实测的编号：IO1_5 对应 gpiochip5 的 line 5（内核全局号 gpio-651），数据寄存器物理地址为 `0xffec006000`，编程时使用 gpiochip5 加 line 5。
- 演示了如何用 gpioset 控制 IO1_5，并通过内核的 `/sys/kernel/debug/gpio` 视图确认电平变化；同时讲清了 gpioset 是持线命令，进程不结束就会一直占用这根线，以及如何用 pkill 释放。
- 新增了完整的 relay-toggle 示例程序，覆盖 gpiod 的完整生命周期：打开 chip、配置并申请 line 5、拉高、拉低、释放，已在板子上验证。它与实验中的 temperature_fan（三函数结构加滞回决策）定位不同，方便对照。
- 增加了面包板与电烙铁的基础知识，包括面包板电源轨、连接孔、隔离凹槽的连通规则和接线安全提示，以及电烙铁与焊锡的使用说明（新增图 4、图 5）。

## 第 4 章

### 与 ruyiSDK 相关的内容

第 4 章的交叉编译工作流与第 3 章一致，同样是激活 `venv-gnu-ruyisdk` 后交叉编译，再拷到板子上运行，Makefile 会按机器自动选择编译器。

### 其他新增内容

- 讲解了 select 模型：让内核同时盯住多个来源，既能及时响应学员输入，又能在采样时间到达时触发采样，并通过超时机制实现「该采样了」的判定。
- 新增了一个完整的命令读取器示例 cmd-demo，采用先分再合的思路：先分别讲解处理函数和命令表（结构体加函数指针），再合成一个完整程序。示例用 help、echo、quit 三个无关命令作为骨架，实验里的 status、set 由学员自己实现，结构与示例保持一致。
- 补充了真实对话片段，帮助学员理解命令行的实际交互过程。

## 其他维护性改动（非知识点）

- 用词标准化：把课件中的非正式表达改为规范说法（例如聊天线改为串口、能跑改为可运行、狂开狂关改为频繁开合），并改写了一些口语化表述。
- 课件结构调整：第 3 章重新组织为四个小节，移除了 consumer-naming 提示框；示例由 fan-toggle 更名为 relay-toggle，与实验中的 temperature_fan 区分开。
- 链接与发布：修正了 GitHub Pages 的 URL，补充了在线预览地址，并说明了 `main` 分支自动发布的机制。
