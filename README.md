## 仓库结构

```text
ruyi-riscv-linux-book/
├── index.html                 # 课程首页（规划中）
├── README.md
├── docs/
│   └── CourseOutline.html     # 课程总大纲
├── chapters/
│   ├── ch01/                  # 第一章 开发环境篇
│   │   ├── lecture.html       # 讲义（阅读 + 投屏）
│   │   ├── lecture.pdf
│   │   ├── lab.html           # 实验
│   │   └── lab.pdf
│   └── ch02/                  # 第二章 工具链与工程
│       ├── lecture.html       # 讲义（含 2.3 选读）
│       ├── lecture.pdf
│       ├── lab.html           # 实验
│       ├── lab.pdf
│       └── code/              # hello、project-template
├── misc/
│   ├── boards/                # 板卡参考资料
│   │   ├── licheepi4a/
│   │   ├── k1/
│   │   └── riscv-ai-boards-2025-2026.md

```
