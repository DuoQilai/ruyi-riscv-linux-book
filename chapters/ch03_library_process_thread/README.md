# 第三章 程序库、进程与线程

## 本章目标

- 将第二章的外设示例整理为可复用的 Linux 应用模块，理解头文件、库文件和主程序之间的边界。
- 掌握静态库、共享库、运行时动态加载、进程控制、IPC 和 pthread 同步的基本方法。
- 在 LicheePi 4A + RevyOS 上形成“采集、处理、显示、服务化运行”的传感器终端程序骨架。
- 能使用 `ldd`、`/proc`、`pstree`、`ipcs`、`journalctl`、`strace` 等工具定位运行问题。

## 前置条件

- 已完成第一章的 RevyOS 启动、SSH/SCP、交叉编译、Makefile、GDB 和 systemd 基础。
- 已完成第二章的 GPIO、DHT22、OLED、PWM/ADC/I2C/SPI 等外设接线和基本读写。
- 熟悉 C 语言结构体、函数指针、头文件拆分、Makefile 变量和 Linux shell 命令。
- 准备 LicheePi 4A、RevyOS、网络连接、DHT22 或可替代的传感器输入，以及可选 OLED 显示模块。

## 知识简介

第二章的程序通常以单文件示例为主，适合验证外设是否工作，但不适合长期维护。本章开始把程序拆成库、进程和线程三个层次：驱动访问封装为库，后台采集整理为进程，实时采集和显示用线程协作。学生需要理解 Linux 应用不是只把代码写长，而是要明确模块边界、运行生命周期、数据同步和异常恢复方式。

本章不追求完整产品源码，而是建立后续第四章文件、日志、Socket、HTTP 与 MQTT 项目的应用基础。完成本章后，学生应能把传感器采集模块作为库复用，把采集任务作为守护进程运行，并能在多进程或多线程结构中安全交换数据。

## 环境准备

| 项目 | 要求 | 检查方式 |
| --- | --- | --- |
| 主机环境 | Linux/macOS 主机，已安装 RuyiSDK 或可用的 RISC-V Linux 交叉工具链 | `riscv64-unknown-linux-gnu-gcc --version` 或课程指定工具链版本可输出 |
| 目标环境 | LicheePi 4A，运行 RevyOS，能通过 SSH 登录 | `ssh lpi4a@<board-ip> uname -a` |
| 编译依赖 | `gcc`、`make`、`binutils`、`gdb`、`gdbserver`、`libc6-dev`，板端具备 `ldd`、`journalctl` | `gcc --version`、`make --version`、`ldd --version` |
| 运行依赖 | pthread、POSIX IPC、syslog、systemd；实验 3.1 需要动态链接器支持 | `getconf GNU_LIBPTHREAD_VERSION`、`systemctl --version` |
| 硬件连接 | DHT22 或课程替代传感器接到 3.3V GPIO；可选 OLED 接 I2C | 先运行第二章对应外设示例确认读数或显示正常 |

## 学习路径

| 讲次 | 主题 | 学习重点 | 对应实验 |
| --- | --- | --- | --- |
| 3.1 | 静态库与共享库 | `.a`、`.so`、SONAME、`ldd`、`rpath`、`dlopen`、`LD_PRELOAD` | 将 DHT22 驱动封装为 `libdht22.so` |
| 3.2 | Linux 进程模型与控制 | `fork`、`exec`、`wait`、僵尸/孤儿进程、守护进程、`/proc` | 守护进程化传感器采集程序 |
| 3.3 | 进程间通信 | pipe、FIFO、POSIX 消息队列、共享内存、信号量、信号处理 | 采集进程通过共享内存向显示进程传递数据 |
| 3.4 | 多线程编程与同步 | pthread、mutex、条件变量、读写锁、生产者-消费者、线程池 | 多线程传感器终端 |

建议先把第二章中能稳定运行的 DHT22 采集函数复制到新的工程目录，再逐步拆成 `include/`、`src/`、`lib/`、`app/`、`build/`。每一讲都保留一个可运行的小程序，不把所有知识点一次性堆到综合程序中。

## 运行验证

| 验证项 | 预期现象 | 记录 |
| --- | --- | --- |
| 库封装 | `make` 生成 `libdht22.so`，`ldd` 能看到动态依赖，主程序可通过 `dlopen` 调用 | 记录库路径、`ldd` 输出和一次读数 |
| 进程控制 | 采集程序可前台运行，也可 daemon 化后台运行，`pstree` 可观察父子关系 | 记录 PID、PPID、`journalctl` 日志 |
| IPC | 采集进程写入共享内存，显示进程能读取同一份温湿度结构体 | 记录共享内存名称、信号量名称和连续 5 次输出 |
| 多线程同步 | 采集线程、处理线程、显示线程无忙等，退出时能 join 并释放资源 | 记录线程启动日志、队列长度变化和退出日志 |
| 异常处理 | 传感器缺失、库路径错误、共享内存权限错误时能输出清晰诊断 | 记录错误命令和错误信息 |

## 本章成果

- 一套可复用的传感器库工程，包含头文件、共享库、测试主程序和 Makefile。
- 一个守护进程化采集程序，能后台运行并输出 syslog 或 systemd journal 日志。
- 一个共享内存 + 信号量的跨进程数据同步示例。
- 一个 pthread 生产者-消费者传感器终端示例。
- 可提交材料：源码目录、构建命令、板端运行截图或日志、实验验收记录、遇到的问题与处理说明。
