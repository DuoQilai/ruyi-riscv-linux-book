# 图片与图表素材

## 说明

本目录存放课程文档、实验指导书和 PPT 引用的图片、截图和图表。素材应服务于正文内容，不存放与课程无关的临时图片。

## 命名规则

图片文件使用以下格式：

```text
fig-章节号-序号-说明.png
```

示例：

```text
fig-01-01-board-interfaces.png
fig-01-02-ruyi-version.png
fig-01-03-revyos-first-login.png
```

## 引用规则

正文引用图片时，需要同时写清图片编号、标题和解释。例如：

```markdown
![图 1-2 ruyi version 输出](assets/fig-01-02-ruyi-version.png)

图 1-2 展示了 `ruyi version` 的输出结果，用于确认 `ruyi` 已正确安装。
```
