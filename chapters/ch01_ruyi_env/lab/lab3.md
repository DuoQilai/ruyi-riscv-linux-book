## 实验目标

## 实验任务

### 任务 1：校验镜像与目标

记录镜像来源、文件名、发布日期、板卡型号、校验值和目标介质。

### 任务 2：烧录并观察启动

按该镜像的发布说明完成烧录，保存完整终端日志。

### 任务 3：完成首次启动检查

确认系统、架构、用户、网络、时间和软件源。

## 实验步骤

1. 计算并比对镜像哈希。

```bash
sha256sum <image-file>
```

2. 让开发板进入镜像说明要求的烧录模式。
3. 使用烧录工具列出设备，确认目标唯一。
4. 按发布说明执行烧录并保存日志。
5. 启动后执行：

```bash
cat /etc/os-release
uname -a
uname -m
id
hostnamectl
ip -br addr
ip route
timedatectl
```

6. 检查软件源：

```bash
grep -R --no-filename -h '^deb ' /etc/apt/sources.list /etc/apt/sources.list.d 2>/dev/null
sudo apt update
```

## 验收记录

| 记录项 | 内容 |
| --- | --- |
| 运行命令 | 校验、烧录、系统与网络检查命令 |
| 关键输出 | 哈希、系统版本、内核、IP、apt 结果 |
| 截图或照片 | 烧录成功、首次登录、串口日志 |
| 异常处理 | 无设备、无启动、无网络或 apt 失败的处理 |

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 校验值不一致 | 下载不完整或文件版本错误 | 删除损坏文件并重新下载 |
| 烧录中断 | 线缆、权限、供电或主机休眠 | 更换可靠连接并重新开始 |
| 无启动画面 | 显示通道问题或镜像未启动 | 使用串口判断实际启动状态 |
| apt 失败 | 网络、DNS、时间或仓库问题 | 按错误类型分别排查 |
