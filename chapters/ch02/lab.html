本章实验 · 改代码闯关

接讲义 2.1–2.4 · 先核对 project-template，再闯 fake-thermostat

说明

讲义已跟做 hello / project-template，并打透：类型与控制流、函数与多文件、编译 → 链接 → _start → main、指针与结构体，以及后续章节会出现的字符串/位运算/函数指针/宏。

本实验在此之上递进两步：先用已熟悉的 project-template 把「编译链接」核对成终端输出；再进入故意埋坑的 fake-thermostat，把比较、字段、指针、错误分支改对。温度来自内置数组或标准输入，无真 DHT。

  • 核对工程：chapters/ch02/code/project-template/（讲义已跑通；此处只取产物证据）
  • 闯关工程：chapters/ch02/code/fake-thermostat/（半成品主要在 src/thermo.c）
  • 输入：默认内置温度序列；也可用 --stdin 读浮点数（负数表示本轮「读失败」）
  • 输出：每步打印温度与风扇 ON/OFF；读失败打印 READ_FAIL 并保持上一风扇状态
前置：已读完讲义 2.1–2.4，且讲义中的 project-template 已能 make 出 ./build/app。本机 gcc / make；本章本机编译，不必上板。
不要一上来大段重写闯关代码。先跑通半成品，对照关卡表，一次只改一类 bug。脚手架内 README.md 与源码注释里的 L1–L4 可对照。

步骤 0：编译链接核对（project-template）

目的：把讲义 2.2 里的机制落到可复查输出。若讲义跟做时已做过且产物仍在，可快速复核后进入闯关。

$ cd chapters/ch02/code/project-template
$ make CROSS_COMPILE=
$ ls build/
$ file build/*.o build/app
# .o 与可执行文件角色不同；app 应能执行
$ nm build/app | grep -E '_start|main' || true
# 通常能同时看到 main 与启动相关符号（有 nm 时）
$ ./build/app

可选：临时改错 greet.c 里的函数名再 make，应出现 undefined reference——改回后重新 make 通过。这证明「编译过了、链接对不上」与「对上了」的差别。

本步成功判据：build/ 中有对应 .o 与 app；file 能区分二者；./build/app 能跑。然后进入闯关，不再停留在本模板。

步骤：fake-thermostat 闯关

1. 构建与首次运行（先看坏现象）

进入闯关目录，编译并运行。半成品会编译通过，但决策是错的——故意如此，用来对照关卡表。

$ cd chapters/ch02/code/fake-thermostat
$ make
$ ./build/fake-thermo
# 观察内置序列下的温度与风扇输出，记下「哪里不对」

# 也可用 stdin 喂温度（一行一个浮点数；负数表示读失败）
$ printf '25\n27\n29\n27\n24\n-1\n' | ./build/fake-thermo --stdin

本步成功判据：能编译出 ./build/fake-thermo 并看到每步输出；当前行为与下方「修好后期望表」不一致（坑还在）。

2. 按关卡改代码（一次一类）

滞回控温：温度高于上限才开风扇，低于下限才关风扇；夹在中间时保持上一状态。默认：t_high = 28.0，t_low = 26.0，初始风扇 OFF。

主要改 src/thermo.c 里的 thermo_decide 与 thermo_read。每修完一关，重新 make 再跑。

关卡修好前你会看到什么你要改成什么（成功判据）主要坑类型
L1 温度升高时风扇反而关，或该开不开、该关不关 比较方向正确：temp > t_high → 风扇 ON；temp < t_low → 风扇 OFF；中间保持 错误比较
L2 阈值「怎么改都不对劲」，行为像拿错了结构体里的另一个字段 决策只使用 cfg->t_high 与 cfg->t_low，不要误用 period_ms 结构体字段用错
L3 传入空配置指针或空风扇状态指针时崩溃 thermo_decide / thermo_read 在指针为 NULL 时安全返回 指针使用
L4 读失败时仍用垃圾温度做决策，或失败路径却返回「成功」 thermo_read 失败时返回非 0 且不写输出；主循环打印错误并跳过本轮决策，保持上一风扇状态 缺少错误分支

修 L3 时，可对 thermo_decide(NULL, …) / thermo_read(NULL) 调用一次确认不崩溃。修 L4 时，内置序列最后一步会注入读失败，应出现 READ_FAIL。

3. 对照内置序列做最终验收

四关都修好后，运行 ./build/fake-thermo（默认内置序列）。期望（初始风扇 OFF）：

步温度 °C期望风扇说明
125.0OFF低于下限，保持关
227.0OFF滞回带中间，保持上一状态
329.0ON高于上限，打开
427.0ON仍在中间带，保持开
524.0OFF低于下限，关闭
6读失败（哨兵）保持 OFF打印 READ_FAIL，不根据垃圾温度改风扇

本步成功判据：六步输出与上表一致；能口头指出半成品里至少三类坑（比较、字段、指针、错误分支中任选）。
