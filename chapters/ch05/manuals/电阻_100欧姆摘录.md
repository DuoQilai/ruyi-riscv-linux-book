# 金属膜电阻摘录（1/4W · 1%）

来源：采购规格（telesky 金属膜电阻编带）；实物为浅蓝圆柱体、五色环，引脚两端贴纸带。

淘宝整页超长截图 PDF 体积过大；本文件只保留元件用法。

## 通用结论

| 项 | 说明 |
|----|------|
| 类型 | 金属膜电阻，通孔直插 |
| 功率 | **1/4 W** |
| 精度 | **±1%**（五环末环多为棕） |
| 极性 | **无** |
| 包装 | 编带：纸带固定引脚，掰下一根使用 |

## 色环速查（五环 · 本课常见库存）

| 阻值 | 常见色环（示意） |
|------|------------------|
| **100 Ω** | 棕·黑·黑·黑·棕 |
| **220 Ω** | 红·红·黑·黑·棕 |

以实物色环与订单选项为准；拿不准用万用表量一次。

## 作 LED 限流时

串在电源/GPIO 与 LED 正极之间即可。无软件 API。LED 电气参数见 `LED_UR5202D摘录.md`。
