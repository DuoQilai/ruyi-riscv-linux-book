# AMS1117 降压小板（3.3V → 1.8V 供电）

本课用途（人话）：  
荔枝派排针上有 **3.3V**，没有 **1.8V**。  
你已买的 **TXS0108E 电平转换板**，有一侧电源必须吃 **1.8V**。  
这块小板的作用就是：**把 3.3V 变成 1.8V，专门喂给转换板那一侧。**

它不管温度、不管风扇、不管继电器开关。只供电。

## 板上大概长什么样（到货后对照）

常见三根针（丝印可能略有不同）：

| 常见丝印 | 人话 | 接到哪里 |
|----------|------|----------|
| **IN / VIN / +**（输入） | 进电 | 荔枝派排针 **3.3V** |
| **GND / -** | 地 | 荔枝派排针 **GND**（和转换板地连在一起） |
| **OUT / VOUT**（输出） | 出电 | **TXS0108E** 上要 **1.8V** 的那个电源脚（丝印常写 **VCCA**） |

注意：

- 输入要比输出高一点才行。用排针 **3.3V** 喂它，输出 **1.8V**，符合这个要求。  
- **不要**拿风扇的 5V 大电流回路当这事的主线；这小板只给转换板喝一口小电流。  
- 接反输入输出可能烧模块，到货后先认清 **IN / OUT / GND** 再接线。

## 和整套硬件的关系（一张表）

| 你买的东西 | 干什么 |
|------------|--------|
| DHT22 | 测温湿度 |
| 继电器 + 5V 风扇 | 超温时让风扇转 |
| TXS0108E | 板子脚（约 1.8V）和模块脚（约 3.3V）之间翻译信号 |
| **本 AMS1117-1.8V 小板** | **给 TXS0108E 缺的那一侧电源补 1.8V** |
| 荔枝派 Fan Power 插座 | 板载散热风扇用，**与实验风扇无关** |

## 到货后建议先做的两步（不用写程序）

1. 只接 **IN←3.3V、GND←地**，用万用表（若有）量 **OUT**，应大约 **1.8V**。  
2. 确认无误后，再把 **OUT** 接到转换板的 **VCCA**，转换板另一侧电源接排针 **3.3V**，地共地。

没有万用表：看小板指示灯是否亮；再按教程整套联调，若转换板完全没反应，回头查这根 1.8V 是否接上。
