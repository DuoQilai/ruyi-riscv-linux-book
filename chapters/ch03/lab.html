本章实验 · 继电器控制风扇

接讲义 3.1–3.3 · 接线后首次跑 temperature_fan，再改阈值

说明

讲义已打透：用户态经内核改 GPIO、chip/line 与本板 1.8 V、独占申请、以及 set_value 之后可用只读 devmem 看见寄存器位翻转；并用 gpioset 跟做控过继电器信号端。

本实验在此之上递进：按表完成整板接线（含风扇负载回路），第一次跑通 temperature_fan 假温度闭环，再改阈值观察开/关点变化。不再重讲 MMIO / gpiod 机制，也不再把讲义里的 gpioset 跟做重写一遍。

  • 工程：chapters/ch03/code/temperature-fan/
  • 脚：本课 RevyOS 默认 gpiochip5 line 5 / 丝印 IO1_5
  • 输入：程序内部假温度（无 DHT22）
  • 输出：终端假温度与 fan ON/OFF；继电器吸合/释放；风扇转/停
成功时你能演示：终端周期性打印假温度；升过上限 [INFO] fan ON 且风扇转；降到下限以下 fan OFF 且风扇停；改过阈值后开/关点跟着变。
安全：风扇大电流必须经继电器触点，不要直接接信号脚。板子上标着 Fan Power 的白色插座是板载散热风扇用的，跟本实验风扇无关，别插错。接线时尽量断电。

荔枝派排针怎么认

板子侧面那排竖针是 20 针排针。信号脚高电平约 1.8V；本课光耦继电器可直连（讲义 3.2 已说明原因）。

排针上的字本课用途
5V继电器线圈；经继电器给风扇供电
GND共地
IO1_5继电器信号脚（默认）
IO1_6备用（第四章 DHT22）
插针方位图见仓库 chapters/ch03/manuals/lpi4a-wiki-assets/io_map.png。以文档图为准；早期板丝印可能不准。编号若与默认不符，按讲义：认丝印、查运行时 chip/line。

接线总表（照抄）

先认清每块板子上的丝印，再接线。丝印若和表不完全一致，以实物丝印为准，逻辑按下表角色对应。

A. 继电器（信号 + 供电）

从到说明
排针 IO1_5继电器信号脚 IN / X1GPIO 直连
排针 5V继电器 V+ / VCC线圈要 5V
排针 GND继电器 V- / GND共地，必接

跳线帽拨到 H（高电平有效）。

B. 风扇（走继电器触点）

接法说明
排针 5V → 继电器 NO（常开）平时断开
继电器 COM → 风扇红线吸合后红线才有电
风扇黑线 → 排针 GND负极回地
排针 5V ──► [继电器 NO]──(吸合时接通)──[COM]──► 风扇红线
排针 GND ──────────────────────────────────────► 风扇黑线
排针 IO1_5 ──► 继电器 IN / X1（直连）
排针 5V  ──► 继电器 V+      排针 GND ──► 继电器 V-

步骤 1：接线

  1. 板子断电（拔电源更安心）。
  2. 按总表：先 GND（共地），再 5V，再信号线 IO1_5 → IN，最后接风扇。
  3. 确认跳线帽在 H；没碰到 Fan Power 白色插座。
  4. 再上电。

本步成功判据：继电器电源指示灯亮；未触发时风扇不转；能指着线说出「地 / 信号 / 风扇回路」。

步骤 2：编译运行 temperature_fan

这是本章第一次整板跑假温度程序。程序申请 IO1_5 为输出，用内部假温度跑滞回阈值。板端原生编译最省事：

$ ssh user@board-ip 'cd ~/ruyi-riscv-embedded/ch03-lab && make && sudo ./temperature_fan'

把 user@board-ip 换成第一章能登录的账号和地址。代码未上板时，先按第一章 SCP 传过去。也可用主机交叉编译 + scp。

为什么 sudo？/dev/gpiochip* 默认归 root。若讲义跟做留下的 gpioset 仍占着 line 5，先 sudo pkill -x gpioset。

步骤 3：假温度验收

  • 启动打印 fake temperature: T_HIGH=28.0 T_LOW=26.0，并说明继电器在 IO1_5。
  • 周期性打印 [INFO] temp=…C fan=OFF|ON，假温度在 24~31 之间来回。
  • 升过 28°C → [INFO] fan ON，继电器吸合，风扇转。
  • 降到 26°C 以下 → [INFO] fan OFF，风扇停。
  • 中间区间（26~28）保持上一状态，不狂抖。

停程序：SSH 里 Ctrl+C。

退出与悬浮：若只释放 GPIO，脚会悬浮；本继电器模块输入悬浮时可能飘高 → 风扇一直转。代码在退出前显式拉低再释放（见 temperature_fan.c 的 on_signal() 与收尾）。程序退出后内核仍可能把脚放回悬浮；要退出后也稳定关断，可在继电器 X1 到 GND 加 10kΩ 下拉。

本步成功判据：能演示超温开 / 降温关；Ctrl+C 后风扇不再持续转（或靠 X1 下拉稳定关断）。

步骤 4：改阈值

打开 temperature_fan.c 顶部宏，把 T_HIGH / T_LOW 改成别的数（例如 27 / 25），重新 make 再跑，观察风扇开/关的温度点变了。

也可以把 STEP_DELTA 改大，让温度变化更快、更容易看到切换。

本步要证明的：阈值是程序变量；硬件只跟着高低电平走。这是相对讲义跟做的递进，不是再跑一遍相同验收。
