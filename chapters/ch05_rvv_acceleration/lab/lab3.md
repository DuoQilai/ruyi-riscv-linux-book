# 实验 5.3：RVV SGEMM 矩阵乘法

## 对应讲次

| 项目 | 内容 |
| --- | --- |
| 章节 | 第 5 章 RISC-V 向量扩展（RVV）加速编程 |
| 讲次 | 第 3 讲 常用算法向量化优化 |
| 课程主题 | SGEMM、分块、RVV 乘加、吞吐量 |
| 实验类型 | 必做实验 |

大纲讲次原文：第3讲 常用算法向量化优化。
大纲实验原文：实现 RVV 加速的矩阵乘法（SGEMM），对比 naive C 版本在 LicheePi 4A 上的吞吐量
大纲知识点原文：向量化 memcpy/memset；向量化矩阵乘法；向量化卷积运算；向量化激活函数；向量化图像处理；定点量化推理加速。

## 实验目标

- 实现 `C = A * B + C` 的 naive 标量版和 RVV 版。
- 在多个矩阵规模上验证误差、耗时、GFLOPS 和加速比。
- 分析结果随规模变化的原因。

## 实验任务

### 任务 1：实现基线

实现三重循环 naive SGEMM，使用固定随机种子生成矩阵。

### 任务 2：实现 RVV 版本

选择按行或按列的向量化路径，使用 `vfmacc` 或等价 intrinsics 做浮点乘加。

### 任务 3：记录数据

测试 `64/128/256` 三组方阵；如内存和时间允许，扩展到 `512`。

## 实验步骤

```bash
mkdir -p ~/rvv-labs/lab5_3/results
cd ~/rvv-labs/lab5_3
make clean
make CFLAGS="-O3 -march=rv64gcv -mabi=lp64d"
```

```bash
./bench_sgemm --m 16 --n 16 --k 16 --check
for s in 64 128 256; do
  ./bench_sgemm --m $s --n $s --k $s --repeat 5 --check \
    | tee results/sgemm_${s}.txt
done
```

可选 OpenBLAS 单线程对比：

```bash
OPENBLAS_NUM_THREADS=1 ./bench_sgemm --impl openblas --m 256 --n 256 --k 256 --repeat 5
```

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 结果误差过大 | B 矩阵布局或索引错误 | 用 2x3、3x2 手算矩阵调试。 |
| RVV 不明显更快 | 访存布局不友好 | 尝试转置 B 或分块。 |
| 测试太慢 | naive 规模过大 | 先完成 64/128，512 作为拓展。 |
