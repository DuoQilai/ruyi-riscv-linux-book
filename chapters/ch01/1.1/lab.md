## 实验目标

- 正确识别课程中的 ISA、SoC、开发板、操作系统和开发工具。
- 识别 LicheePi 4A 的关键接口并记录连接用途。
- 建立可执行的个人软硬件准备清单。

## 硬件连接或部署关系

| 模块 | 引脚/接口 | 连接说明 | 注意事项 |
| --- | --- | --- | --- |
| 电源 | 板卡指定供电口 | 使用符合规格的稳定电源 | 不使用来源不明的电源 |
| 数据连接 | 板卡指定 USB 数据口 | 用于烧录或设备连接 | 线缆必须支持数据 |
| 调试串口 | TX、RX、GND | 连接 3.3 V USB-TTL | TX/RX 交叉，禁止接 5 V |
| 网络 | Ethernet 或 Wi-Fi | 用于 SSH 与软件源访问 | 记录网络条件 |

## 实验任务

### 任务 1：完成平台分层

将 RISC-V、TH1520、LicheePi 4A、RevyOS、`ruyi` 和课程应用放入正确层次。

### 任务 2：标注开发板接口

拍摄或使用课程提供的板卡图片，标注供电、数据、串口、网络、启动介质和扩展接口。

### 任务 3：建立环境清单

列出主机系统、开发板、电源、数据线、串口模块、网络条件和待安装软件，并标记状态。

## 实验步骤

1. 记录主机系统和架构。

```bash
uname -a
uname -m
```

2. 填写平台分层表，不允许把软件、硬件和 ISA 写在同一层。
3. 对照板卡资料完成接口标注。
4. 检查 USB 线是否标明数据能力，检查 USB-TTL 模块逻辑电平。
5. 汇总“已有、缺少、待确认”三类项目，给出补齐计划。

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 无法确认板卡版本 | 只看商品页面，未看实物丝印 | 拍摄板卡正反面并核对官方资料 |
| USB-TTL 标注不清 | 模块资料缺失 | 暂不接板，先确认逻辑电平 |
| 主机不是 Linux | 使用 macOS 或 Windows | 记录差异，准备课程支持的 Linux 环境 |
