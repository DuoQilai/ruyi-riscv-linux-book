# 2.3 UART 串口通信

大纲知识点原文：UART 通信协议基础；LicheePi 4A UART 引脚识别；termios 串口配置；串口收发程序；环形缓冲区设计；简易串口调试终端。

UART 通信协议、LicheePi 4A UART 引脚、termios 串口配置、串口收发、环形缓冲区、简易串口调试终端。

## 目标

学生能通过 USB-TTL 与板端 UART 双向通信，并实现可回显的命令终端。

## 讲授要点

- USB-TTL 必须交叉连接 TX/RX，并共地；不要把 5V 接到 3.3V 信号引脚。
- 串口通信两端参数必须一致：波特率、数据位、校验、停止位和流控。
- 串口数据是字节流，不天然按命令分包，需要缓冲区和分隔符解析。
- 命令终端会作为后续温控项目的本地调试入口。

## 操作或演示

```bash
ls -l /dev/ttyS* /dev/ttyUSB* 2>/dev/null
stty -F /dev/ttyS0 115200 cs8 -cstopb -parenb -ixon -ixoff
```

主机端可用串口终端连接 USB-TTL。

```bash
picocom -b 115200 /dev/ttyUSB0
```

板端运行命令终端程序。

```bash
./uart_console --dev /dev/ttyS0 --baud 115200
```

## 运行验证

| 验证项 | 命令或操作 | 预期现象 |
| --- | --- | --- |
| 设备节点 | `ls /dev/tty*` | 能找到目标 UART 设备 |
| 参数配置 | `stty -F /dev/ttyS0 -a` | 显示 115200 8N1，无软件流控 |
| 回显 | 输入 `hello` | 板端返回相同文本或带前缀文本 |
| 命令解析 | 输入 `help` | 返回支持命令列表 |
| 状态查询 | 输入 `status` | 返回程序运行状态 |

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 全是乱码 | 波特率或串口参数不一致 | 两端统一为 115200 8N1 |
| 没有任何输出 | TX/RX 未交叉、未共地、设备节点错误 | 检查接线和 `/dev/tty*` |
| 程序阻塞无法退出 | read 阻塞且未处理信号 | 使用 `select` 或非阻塞模式 |
| 命令被拆开 | 串口按字节流到达 | 使用环形缓冲和换行符作为命令结束 |
