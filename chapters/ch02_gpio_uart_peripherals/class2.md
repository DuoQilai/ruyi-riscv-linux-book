# 2.2 GPIO 输入与交互逻辑

## 对应大纲

大纲讲次原文：第2讲 GPIO 输入与交互逻辑。
大纲知识点原文：按键电路接线；GPIO 输入读取；中断方式检测按键；按键消抖算法；组合按键与长按/短按识别；按键控制 LED 实战。

按键电路接线、GPIO 输入读取、中断方式检测按键、按键消抖、长短按/双击识别、按键控制 LED。

## 目标

学生能实现按键消抖和交互状态机，用单击、长按、双击控制 LED 模式。

## 讲授要点

- 机械按键不是理想数字信号，抖动会导致一次按压被识别成多次事件。
- 轮询适合入门理解，边沿事件适合实际程序降低 CPU 占用。
- 长按、短按、双击不要写成零散 if，应先抽象为事件，再交给 LED 状态机处理。
- 输入线的 active_low 必须和接线方式一致，否则所有逻辑都会反向。

## 操作或演示

```bash
gpiomon --num-events=5 gpiochipX Y
```

演示按键按下和释放时边沿事件变化，再展示程序结构：读取事件、消抖确认、生成 `CLICK`/`LONG_PRESS`/`DOUBLE_CLICK`、更新 LED 模式。

```bash
./button_led --chip gpiochipX --button 12 --button 13 --leds 20,21,22,23
```

## 运行验证

| 验证项 | 命令或操作 | 预期现象 |
| --- | --- | --- |
| 输入读取 | `gpioget gpiochipX Y` | 按下/松开电平变化 |
| 边沿事件 | `gpiomon` | 每次按压产生可观察事件 |
| 单击 | 短按按钮 1 | LED 模式切换 |
| 长按 | 按住按钮 1 超过阈值 | 流水灯速度变化 |

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 一次按压触发多次 | 未消抖或消抖时间太短 | 设置 20 到 50 ms 消抖窗口并记录测试结果 |
| 按下无事件 | 接线错误、没有上拉/下拉、line 错误 | 用万用表和 `gpioget` 逐步检查 |
| 长按被识别成短按 | 时间阈值设置不合理 | 记录按下和释放时间戳，调整长按阈值 |
| CPU 占用高 | 忙轮询没有休眠 | 改用 `poll`/`epoll` 或增加合理 sleep |
