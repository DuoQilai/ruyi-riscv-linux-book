## 实验目标

- 搭建 2 个按键和 4 路 LED 的交互电路。
- 使用 gpiod 读取按键输入，并观察边沿事件。
- 实现 20 到 50 ms 软件消抖。
- 实现单击切换 LED 模式、长按调节速度、双击切换显示方向。

## 实验任务

### 任务 1：验证按键输入

用 `gpioget` 和 `gpiomon` 分别观察按键电平和边沿事件。

### 任务 2：实现消抖状态机

程序把原始边沿转换为稳定事件，至少包含 `IDLE`、`DEBOUNCE`、`PRESSED`、`RELEASED` 状态。

### 任务 3：实现 LED 交互

KEY1 单击切换模式，KEY1 长按降低或提高速度，KEY2 双击切换方向或随机模式。

## 实验步骤

1. 检查输入 line。

```bash
gpioinfo gpiochipX
gpioget gpiochipX <key1-line> <key2-line>
gpiomon --num-events=6 gpiochipX <key1-line>
```

2. 编译交互程序。

```bash
make clean
make TARGET=button_led
scp build/button_led <user>@<board-ip>:/tmp/button_led
```

3. 运行程序并打开事件日志。

```bash
ssh <user>@<board-ip> 'chmod +x /tmp/button_led'
ssh <user>@<board-ip> '/tmp/button_led --chip gpiochipX --leds 20,21,22,23 --keys 12,13 --debounce-ms 30 --long-ms 800 --double-ms 300'
```

4. 按测试表执行人工测试。

```text
KEY1 短按 5 次：LED 模式应逐次切换
KEY1 长按 3 次：速度应按档位变化
KEY2 双击 5 次：方向或模式应切换
快速抖动按键 10 秒：不得出现连续误触发
```

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 未按下也触发 | 输入悬空或偏置错误 | 增加上拉/下拉，确认 active_low |
| 长按经常失败 | 阈值太长或释放检测错误 | 记录时间戳，调整 `--long-ms` |
| 双击识别困难 | 双击窗口太短或消抖过长 | 调整 `--double-ms` 和 `--debounce-ms` |
| LED 响应延迟明显 | 事件循环阻塞在 LED 延时 | 使用短周期刷新或事件驱动调度 |
