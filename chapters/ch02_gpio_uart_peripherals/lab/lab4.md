# 综合项目 2.4：双温度传感器 + 温控风扇

## 对应讲次

| 项目 | 内容 |
| --- | --- |
| 章节 | 第 2 章 GPIO、UART、常用外设 |
| 讲次 | 第 4 讲 |
| 课程主题 | PWM/ADC/I2C/SPI 与综合传感器 |
| 实验类型 | 阶段综合项目 |

大纲讲次原文：第4讲 PWM/ADC/I2C/SPI 与综合传感器。
大纲实验原文：搭建 2 路温度传感器 + 风扇控制电路，检测室内温度低于/高于阈值时自动控制风扇转动，并在 OLED/串口输出实时状态
大纲知识点原文：PWM 输出控制；ADC 模拟量采集；I2C 总线与设备扫描；OLED 显示屏驱动（SSD1306）；DHT22 温湿度传感器；温控风扇综合控制。

## 实验目标

- 搭建 DHT22 x2、SSD1306 OLED、风扇/继电器或 MOSFET 驱动电路。
- 采集两路温湿度数据，完成校验、重试和异常读数保护。
- 使用阈值和回差控制风扇启停，避免频繁开关。
- 在 OLED 和串口同时显示两路温度、阈值、风扇状态和异常状态。

## 硬件连接或部署关系

| 模块 | 引脚/接口 | 连接说明 | 注意事项 |
| --- | --- | --- | --- |
| DHT22-A | 1 个 GPIO line | VCC、GND、DATA 接目标 GPIO，DATA 上拉 | 记录传感器编号 A |
| DHT22-B | 1 个 GPIO line | 与 A 使用不同 GPIO line | 两路数据结构独立 |
| SSD1306 OLED | I2C SDA/SCL | 接 LicheePi 4A I2C 总线和 3.3V/GND | 常见地址为 `0x3c`，以扫描为准 |
| 风扇驱动 | 1 个 GPIO 或 PWM line | GPIO 控制继电器或 MOSFET，风扇用外部电源 | GPIO 不得直接给风扇供电 |
| 外部电源 | 风扇电源输入 | 按风扇额定电压供电 | 控制侧与开发板共地 |
| 串口或 SSH | 调试通道 | 输出状态日志 | 便于无 OLED 时验收 |

## 实验任务

### 任务 1：完成分模块验证

分别验证 OLED I2C 地址、两路 DHT22 读数、风扇驱动开关，确认每个模块独立可用。

### 任务 2：实现温控逻辑

默认配置为启动阈值 `30.0 C`，回差 `2.0 C`。任一路有效温度大于等于 `30.0 C` 时启动风扇；两路有效温度都小于等于 `28.0 C` 时停止风扇。

### 任务 3：实现异常读数保护

温度低于 `-10.0 C`、高于 `60.0 C`、校验失败或连续读取超时均视为异常。单次异常不改变风扇状态；连续 3 次异常时在 OLED/串口显示 `SENSOR_ERR`，并按教师要求选择保持当前状态或进入安全开启状态。

### 任务 4：完成状态显示

OLED 和串口至少显示：`T1`、`T2`、`Fan`、`On/Off threshold`、`ErrA/ErrB`、更新时间。

## 实验步骤

1. 安装工具并扫描 I2C。

```bash
sudo apt update
sudo apt install -y gpiod i2c-tools
i2cdetect -l
sudo i2cdetect -y <i2c-bus>
```

2. 单独测试风扇驱动。先不接风扇或使用指示灯确认继电器/MOSFET 逻辑，再接入外部电源和风扇。

```bash
gpioset gpiochipX <fan-line>=1
sleep 2
gpioset gpiochipX <fan-line>=0
```

3. 编写或配置项目参数。

```text
dht_a_line=<line-a>
dht_b_line=<line-b>
fan_line=<fan-line>
i2c_bus=<bus>
oled_addr=0x3c
threshold_on_c=30.0
hysteresis_c=2.0
min_valid_c=-10.0
max_valid_c=60.0
max_error_count=3
```

4. 编译并部署项目。

```bash
make clean
make TARGET=temp_fan
scp build/temp_fan <user>@<board-ip>:/tmp/temp_fan
```

5. 运行项目并观察状态。

```bash
ssh <user>@<board-ip> 'chmod +x /tmp/temp_fan'
ssh <user>@<board-ip> '/tmp/temp_fan --chip gpiochipX --dht 12,13 --fan 18 --i2c-bus 1 --oled 0x3c --on 30.0 --hys 2.0'
```

6. 验证阈值、回差和异常保护。

```text
常温测试：记录 T1/T2、Fan=OFF。
升温测试：用手掌或温和热源靠近 DHT22，任一路达到 30.0 C 后 Fan=ON。
回差测试：温度下降到 28.0 C 以下后 Fan=OFF。
异常测试：临时断开一路 DHT22 DATA，OLED/串口显示对应 Err 计数，风扇不因单次异常乱跳。
恢复测试：重新接回传感器，连续有效读数后异常状态清零。
```

## 常见问题

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| DHT22 经常校验失败 | 线太长、上拉不合适、用户态时序受干扰 | 缩短线长，检查上拉，增加重试和失败计数 |
| OLED 无显示 | I2C 总线号或地址错误，SDA/SCL 接反 | 重新扫描总线，断电检查接线 |
| 风扇不转 | 外部电源未接、驱动模块逻辑反、GPIO line 错误 | 单独用 `gpioset` 测试驱动和风扇 |
| 风扇频繁启停 | 回差太小或阈值接近环境温度 | 将回差设为 1 到 3 摄氏度并复测 |
| 异常读数导致误动作 | 未做范围判断或连续异常判断 | 加入 `min/max` 范围、校验失败和连续异常保护 |
